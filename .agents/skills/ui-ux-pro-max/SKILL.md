# UI/UX Pro Max — Suite de Design Avançado

Suite completa de skills de design para agentes, com suporte a geração de
logos, ícones, slides, banners e sistemas de design com tokens.

## Sub-Skills Disponíveis

### design
Design abrangente: logos, ícones, CIP (Creative Image Prompts), slides.

**Banco de dados incluído:**
- Estilos de logo por indústria (12.000+ entradas)
- Paletas de cores por psicologia e indústria
- Estilos de ícones
- Layouts de slides e templates

**Uso:** Quando o usuário pedir um logo, ícone, ou material visual para
uma marca ou produto.

### design-system
Criar e manter sistemas de design completos com tokens hierárquicos.

**Tokens suportados:**
- Primitive tokens (cores brutas, espaçamentos, fontes)
- Semantic tokens (primary, secondary, surface, etc.)
- Component tokens (button-primary, card, input, etc.)
- States & variants (hover, active, disabled)

**Integração:** Tailwind CSS, CSS custom properties, JSON

**Uso:** Quando o projeto precisar de consistência visual ou tiver
múltiplos componentes para padronizar.

### brand
Identidade de marca completa: guidelines, paletas, tipografia, voz.

**Entregáveis:**
- Brand guidelines document
- Color palette management
- Logo usage rules
- Typography specifications
- Voice framework
- Consistency checklist

**Uso:** Quando o projeto precisar de uma identidade de marca definida.

### ui-styling
Styling premium com tipografia curada e sistema de fontes completo.

**Fontes incluídas (com arquivos TTF):**
Arsenal SC, BigShoulders, Boldonse, BricolageGrotesque, CrimsonPro,
DMMono, EricaOne, GeistMono, Gloock, IBMPlexMono, IBMPlexSerif,
InstrumentSans, InstrumentSerif, Italiana, JetBrainsMono, e muitas mais.

**Uso:** Quando o projeto precisar de tipografia premium ou styling
consistente e profissional.

### slides
Criação de apresentações profissionais em HTML com layouts, estratégias
de copywriting e templates.

### banner-design
Design de banners em múltiplos tamanhos e formatos.

## Quando Ativar

- Usuario pedindo logo ou identidade visual → design + brand
- Usuario pedindo sistema de design → design-system
- Usuario pedindo apresentação → slides
- Usuario pedindo banner ou material de marketing → banner-design + design
- Usuario pedindo UI com tipografia premium → ui-styling
